# Calculadora Simples

Uma calculadora simples feita em JavaScript/HTML/CSS para realizar operações básicas como soma, subtração, multiplicação e divisão.

---

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Interface limpa e fácil de usar
- Responsiva para diferentes tamanhos de tela

---

## Tecnologias usadas

- HTML
- CSS
- JavaScript
